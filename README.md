# Demo: Página de Nutricionista (Projeto Conceitual)

Landing page responsiva para uma nutricionista, criada como **projeto de portfólio front-end**.

> **Aviso:** este é um projeto conceitual. O nome "Helena Duarte", o registro profissional, os depoimentos, os números, os contatos e o endereço são **fictícios**. As imagens foram **geradas por IA**. Nenhum dado aqui representa uma profissional real.

🔗 **Demonstração:** [adicione aqui o link da Vercel]

## Objetivo

Praticar a construção de uma página de serviços completa, do layout à responsividade, usando apenas HTML, CSS e JavaScript puros, com foco em conversão (botões de agendamento repetidos ao longo da página).

## Seções da página

- Cabeçalho fixo com menu (hambúrguer no celular)
- Hero com chamada principal e botões de ação
- Sobre
- Atendimentos
- Como funciona (passo a passo)
- Depoimentos (ilustrativos)
- Dúvidas frequentes (FAQ)
- Chamada final e rodapé

## Tecnologias

- **HTML5** semântico
- **CSS3**: variáveis, Flexbox, Grid e media queries (mobile first)
- **JavaScript** puro: menu mobile e ano automático no rodapé
- **Google Fonts**: Fraunces e DM Sans
- **Material Symbols**: ícones

## Destaques técnicos

- Layout responsivo (celular, tablet e computador)
- FAQ com a tag `<details>`, sem JavaScript
- Paleta e fontes centralizadas em variáveis CSS
- Acessibilidade básica: `aria-label`, `aria-expanded`, `alt` nas imagens e textos de contraste legível

## Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/demo-nutricionista.git
   ```
2. Abra a pasta no VS Code.
3. Abra o `index.html` no navegador, ou use a extensão **Live Server**.

Não há dependências nem etapa de build.
